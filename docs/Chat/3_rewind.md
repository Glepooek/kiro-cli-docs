# Rewind

`/rewind` 命令允许您回到对话中任意之前的轮次并向新的方向分支。您可以在事情偏离您想要的方向时分叉会话，而不是重新开始或手动撤销更改。

## 工作原理

当您运行 `/rewind` 时，Kiro 会创建一个从您选择的轮次开始的新会话。原始会话保持完整，因此您可以随时切换回它。

> **注意**
>
> 回溯会创建一个新的对话分支 — 它不会撤销后续轮次中做出的文件更改。您磁盘上的文件保持原样。如果需要还原文件更改，请使用版本控制系统。

```bash
# 打开交互式轮次选择器
/rewind

# 直接跳转到第 4 轮
/rewind 4
```

交互式选择器显示:

- 每轮的提示预览
- 该时刻的上下文窗口使用百分比
- 轮次按最新优先列出，便于快速访问最近的历史

## 典型工作流程

1. 您在对话进行中意识到代理在几轮前走上了错误的道路
2. 运行 `/rewind` 并选择事情仍然正常的那一轮
3. Kiro 从该点创建一个新会话
4. 发送不同的提示以引导对话朝更好的方向发展
5. 要返回原始会话，使用 `/chat resume` — 原始会话永远不会被修改

## 使用场景

- **回溯** — 代理在三轮前做出了错误假设，此后所有内容都建立在此之上
- **探索替代方案** — 您想尝试不同的方法来解决同一问题，同时不丢失第一次尝试
- **从上下文污染中恢复** — 积累了太多无关上下文，您想要一个更干净的起点
- **A/B 测试提示** — 在同一轮次分叉并使用不同指令来比较结果
