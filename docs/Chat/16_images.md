# 处理图像

Kiro 可以在您的聊天会话中直接分析和讨论图像。您可以通过将图像拖放到终端窗口或使用带 Image 模式的 `read` 工具与 Kiro 共享图像。

## 拖放图像

与 Kiro 共享图像最简单的方法是直接将其拖放到终端窗口。当您将图像拖入终端时:

1. 图像路径自动插入到您的提示中
2. 然后您可以添加文本以提供关于您希望 Kiro 对图像做什么的上下文
3. Kiro 将处理图像并根据其内容响应

示例:

```
Kiro> /path/to/architecture-diagram.png 您能解释这个架构并生成实现它的示例代码吗？
```

## 使用 fs_read 处理图像

您还可以显式使用 `read` 工具共享图像:

```
Kiro> 您能分析 /path/to/screenshot.png 处的截图吗？
```

当您提到图像文件时，Kiro 会自动建议使用带 Image 模式的 fs_read。

## 从剪贴板粘贴图像

您可以使用以下命令从系统剪贴板粘贴图像:

```
/paste
```

## 图像使用场景

与 Kiro 共享图像的常见用例包括:

- 分析错误消息截图以进行故障排除
- 将架构图转换为代码实现
- 讨论 UI/UX 设计并生成相应的 HTML/CSS
- 理解流程图并将其转换为算法
- 审查作为图像共享的代码片段
- 解释技术图表以用于文档

## 支持的格式和限制

支持的图像格式包括 JPEG/JPG、PNG、GIF 和 WebP。图像大小必须在 10MB 以下，您可以在单个请求中共享最多 10 张图像。

为获得最佳效果:

- 使用具有清晰文本的高分辨率图像
- 提供关于您希望 Kiro 对图像做什么的具体说明
- 对于复杂的图表，考虑提供额外的上下文
