# Effort

`/effort` 命令控制模型对提示词应用的推理程度。较低的 effort 级别产生更快、更短的响应。较高级别则花费更多 token 进行深度分析、多步推理和全面的代码生成。

## 设置 effort 级别

```bash
# 打开交互式选择器
/effort

# 直接设置
/effort high
```

**可用级别:**

| 级别     | 行为                                           |
| -------- | ---------------------------------------------- |
| `low`    | 快速、简洁的响应。适合简单问题和快速查找。     |
| `medium` | 平衡的推理。适用于大多数开发任务。             |
| `high`   | 全面的分析。更适合复杂重构和架构决策。         |
| `xhigh`  | 扩展推理。适用于多文件更改和细微问题。         |
| `max`    | 最大深度。最适合困难调试、安全分析和复杂逻辑。 |

并非所有模型都支持每个级别。选择器仅显示当前模型可用的级别。

**支持的模型:**

| 模型              | 可用级别                                |
| ----------------- | --------------------------------------- |
| Claude Opus 4.7   | `low`, `medium`, `high`, `xhigh`, `max` |
| Claude Opus 4.6   | `low`, `medium`, `high`, `max`          |
| Claude Sonnet 4.6 | `low`, `medium`, `high`, `max`          |

## 何时调整 effort

- **提高** 当代理给出浅显答案、遗漏边界情况或产生不完整实现时
- **降低** 当您需要快速答案且不想等待扩展推理时
- **使用 `max`** 用于安全审查、复杂调试会话，或需要代理考虑多个相互约束的情况
