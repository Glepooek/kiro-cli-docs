# 使用 Git

在 Git 仓库中工作时，Kiro CLI 的模糊查找器是 Git 感知的，使选择和添加相关文件到上下文变得更容易。此功能帮助您快速识别和包含属于 Git 仓库的文件。

## Git 感知选择如何工作

Git 感知模糊查找器自动与您仓库的 Git 信息集成，提供增强的文件选择能力:

- 识别仓库中的 Git 跟踪文件
- 在文件旁边显示 Git 状态指示器
- 根据 Git 历史优先显示相关文件

## 使用 Git 感知文件选择

### 使用 git 感知文件选择

1. 在终端中导航到您的 Git 仓库。
2. 运行 /context add 命令:

   ```
   /context add
   ```

3. 在模糊查找器界面中，您会看到仓库中的文件及其 Git 状态指示器:
   - `M` – 已修改文件
   - `A` – 已添加文件
   - `?` – 未跟踪文件
4. 输入以过滤文件，使用 Git 状态作为搜索条件的一部分。
5. 使用箭头键导航并按 Enter 选择要添加到上下文的文件。

## Git 感知选择技巧

- 在搜索中使用 Git 状态指示器快速查找已修改或未跟踪的文件
- 模糊查找器优先显示 Git 历史中最近修改的文件
- 被 Git 忽略的文件（通过 .gitignore）仍可用但在结果中优先级较低
