# 文件引用

文件引用允许您使用 `@path` 语法直接在聊天消息中包含`文件内容或目录树`。这提供了快速上下文而无需手动复制内容，并且由于内容在发送前会内联扩展，它避免了工具调用 — 节省 token。

## 基本用法

输入 `@` 后跟文件或目录路径:

```
@src/index.ts             # 包含文件内容
@src/                     # 包含目录树
@./relative/path          # 相对路径
@"path with spaces.txt"   # 带引号的路径（空格必需）
```

引用可以出现在消息的任何位置:

```
审查 @src/auth.ts 的安全问题
比较 @old.json 和 @new.json
@src/ 中处理认证的内容是什么？
```

## Tab 补全

在 `@` 后按 Tab 自动补全路径:

```
@src/<Tab>                # 显示 src/ 中的文件
@package<Tab>             # 补全为 @package.json
@"Screenshot 2024<Tab>    # 补全为 @"Screenshot 2024-01.png"
```

补全可在输入行的任何位置工作。Tab 补全在需要时自动为带空格的路径添加引号。

## 引用如何解析

当引用可能同时匹配提示和文件时:

1. **提示优先**: 如果 `@name` 匹配 `/prompts list` 中的提示，则视为提示
2. **文件其次**: 否则作为文件路径检查
3. **目录再次**: 如果不是文件，则作为目录检查

要强制文件解析（当提示具有相同名称时），使用显式路径: `@./myfile`

## 文件处理

**支持**: 最大 250KB 的文本文件（源代码、配置、markdown）。

**不支持**: 二进制文件（图像、可执行文件、归档文件）显示错误。

大文件在 250KB 处被截断:

```
⚠ 文件 'large-file.json' 被截断（超过 250KB 限制）
```

## 目录树

目录引用扩展为树形列表:

```
@src/
```

扩展为:

```
src/
├── lib/
│   ├── auth.ts
│   └── utils.ts
├── index.ts
└── config.json
```

**限制**:

- 最大深度: 3 层
- 每层最大项目数: 10（如果超出则显示 "... (N more items)"）
- 忽略常见目录: node_modules、.git、target、dist、build

## 示例

**审查文件**:

```
> 审查 @src/auth.ts 的安全问题
```

**比较文件**:

```
> @v1/handler.py 和 @v2/handler.py 有什么不同？
```

**探索结构**:

```
> @infra/cdk/ 的结构是什么？
```

**混合上下文**:

```
> 使用 @serverless.yml 中的配置，更新 @src/lambda/index.ts
```

## 故障排除

| 问题                 | 解决方案                                                   |
| -------------------- | ---------------------------------------------------------- |
| 引用被视为提示       | 存在同名提示。使用显式路径: `@./myfile`                    |
| 文件未找到           | 验证路径相对于当前目录，或使用绝对路径                     |
| 目录太深             | 超过 3 层的子目录不显示。引用特定子目录: `@src/deep/path/` |
| 带空格的路径无法识别 | 使用带引号的语法: `@"path with spaces.txt"`                |

## 当前限制

文件引用当前支持:

- 最大 250KB 的文本文件（更大的文件被截断）
- 最深 3 层、每层 10 个项目的目录树
- 仅显式文件路径（不支持 `@*.ts` 等 glob 模式）
- 完整文件内容（不支持 `@file.ts:10-20` 等行范围语法）
- 相对和绝对路径（不支持 `@~/file` 等波浪号扩展）

不支持二进制文件（图像、可执行文件、归档文件）。
