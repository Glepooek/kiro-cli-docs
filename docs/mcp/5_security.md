# 安全

在将外部 MCP 服务器集成到您的开发工作流程时，安全性至关重要。Kiro CLI 中的 MCP 安全模型基于以下原则设计：
1. **显式权限**：工具在执行前需要显式的用户权限
2. **本地执行**：MCP 服务器在您的机器上本地运行
3. **隔离**：每个 MCP 服务器作为独立进程运行
4. **透明性**：用户可以看到有哪些工具以及它们的功能

## 安全注意事项

在 Kiro CLI 中使用 MCP 服务器时，请牢记以下安全原则：

### 信任和验证

- 只从可信来源安装 MCP 服务器
- 安装前查看工具描述和文档
- 检查安全公告和更新

### 访问控制

- 对服务器权限使用最小权限原则
- 仅将文件系统访问限制在必要的目录
- 尽可能限制网络访问
- 对敏感凭据使用环境变量

### 凭据管理

- 切勿在配置文件中硬编码 API 密钥或令牌
- 对敏感数据使用环境变量
- 定期轮换凭据
- 使用系统密钥链安全存储凭据

### 网络安全

- 对远程 MCP 服务器使用 HTTPS
- 验证 SSL/TLS 证书
- 对需要广泛网络访问的服务器保持谨慎
- 监控网络流量中的异常活动

### 监控和审计

- 定期查看 MCP 服务器日志
- 监控异常行为
- 跟踪已安装的服务器及其权限
- 及时移除未使用或不可信的服务器

## 最佳实践

### 配置安全

```bash
# 对敏感数据使用环境变量
export MCP_API_KEY="your-secure-key"
export DATABASE_URL="your-connection-string"

# 使用环境变量配置 MCP 服务器
kiro-cli mcp add my-server --env MCP_API_KEY --env DATABASE_URL
```
