# TODO 列表

TODO 列表功能使 Kiro 能够自动创建和修改任务列表，同时提供命令供您查看和管理现有的 TODO 列表。

## 入门

TODO 列表在 Kiro 分解复杂任务时自动创建。然后您可以使用 `/todo` 命令管理这些列表。

### 启用 TODO 列表

```bash
kiro-cli settings chat.enableTodoList true
```

### 基本用法

```bash
/todo view      # 查看现有的 TODO 列表
/todo resume    # 恢复一个 TODO 列表
```

## 工作原理

### 自动创建

Kiro 在以下情况下自动创建 TODO 列表：
- 您请求帮助完成多步骤任务
- 复杂问题需要分解
- 您明确请求 TODO 列表

**示例：**

`> 创建一个包含 3 个只读任务的待办列表。

我将为您创建一个包含 3 个只读任务的待办列表。

🛠️  使用工具: todo_list (受信任)
 ⋮ 
 ● TODO:
[ ] 审查项目文档
[ ] 检查系统状态
[ ] 阅读最新更新
 ⋮ 
 ● 0.4秒完成
`

### 任务管理

Kiro 可以：
- 创建 TODO 列表
- 将任务标记为完成
- 添加/删除任务
- 按 ID 加载 TODO 列表
- 搜索现有的 TODO 列表

您可以：
- 查看 TODO 列表
- 恢复 TODO 列表
- 删除 TODO 列表

## 命令

### /todo view

显示并选择一个 TODO 列表以查看其内容，显示任务描述和完成状态。

```bash
/todo view
```

**交互式选择显示：**
- ✓ 已完成的列表（绿色对勾）
- ✗ 进行中的列表及完成计数（红色 X 带进度）

**示例：**

`> /todo view

? 选择要查看的待办列表: ›
❯ ✗ 未完成的待办列表 (0/3)
  ✔ 已完成的待办列表 (3/3)
`

### /todo resume

显示可用 TODO 列表的交互式菜单及其当前进度状态。选择列表会将其加载回您的聊天会话，允许 Kiro 从中断的地方继续。

```bash
/todo resume
```

**示例：**

`> /todo resume

⟳ 恢复: 用于信息收集的只读任务

🛠️  使用工具: todo (受信任)
 ⋮ 
 ● TODO:
[x] 审查项目文档
[ ] 检查系统状态
[ ] 阅读最新更新
 ⋮ 
 ● 0.1秒完成
`

### /todo clear-finished

从存储中删除所有已完成的 TODO 列表。这有助于清理工作空间，删除所有任务已完成的列表。

```bash
/todo clear-finished
```

### /todo delete

删除特定的 TODO 列表或一次删除所有列表。

```bash
/todo delete           # 交互式选择删除一个列表
/todo delete --all     # 删除所有 TODO 列表
```

**选项：**
- `--all` - 无需交互式选择即可删除所有 TODO 列表

## 存储

TODO 列表在会话之间持久化

每个列表保存为 JSON 文件，包含：
- 基于时间戳的唯一 ID
- 任务描述和完成状态
- 已完成任务的上下文更新
- 修改的文件路径
- 整体列表描述

### 目录结构

```
my-project/
├── .kiro/
│   └── cli-todo-lists/
│       ├── 1234567890-task-list.json
│       └── 1234567891-another-list.json
└── src/
    └── main.py
```

## 交互式选择

所有命令使用交互式选择，允许您：
- 使用箭头键导航
- 按 Enter 选择
- 按 Esc 取消

## 最佳实践

### 管理列表

- **定期使用 `clear-finished`** 删除已完成的列表
- **恢复列表** 以继续复杂的多步骤任务
- **检查 `view`** 以查看进度而不恢复

### 工作流集成

- **让 Kiro 自动创建 TODO 列表** 用于复杂任务
- **使用 `resume`** 从之前会话中断的地方继续
- **检查 `view`** 在恢复工作之前查看剩余任务

### 组织

- **在相关项目目录中工作** TODO 列表与项目相关
- **按顺序完成任务** 以获得更好的上下文
- **不再需要时删除旧列表**

## 限制

### 功能

- 无法手动编辑 TODO 列表文件
- 无法合并或拆分 TODO 列表
- 创建后无法重新排序任务

## 故障排除

### 任务不更新

如果任务完成没有被跟踪：
1. **确保 TODO 列表是活动的**：首先恢复列表
2. **让 Kiro 标记任务**：不要手动编辑 JSON 文件
3. **检查错误**：在聊天中查找错误消息

## 工具 vs 命令

### `todo` 工具

`todo` 工具供 Kiro 调用。Kiro 可以：
- 创建 TODO 列表
- 将任务标记为完成
- 添加/删除任务
- 用给定 ID 加载 TODO 列表
- 搜索现有的 TODO 列表

### `/todo` 命令

`/todo` 命令供您管理现有的 TODO 列表。您可以：
- 查看 TODO 列表
- 恢复 TODO 列表
- 删除 TODO 列表
- 清理已完成的列表

## 示例工作流

### 1. 开始复杂任务

`> 我需要为项目设置 CI/CD`

### 2. Kiro 创建 TODO 列表

`🛠️  使用工具: todo_list
 ● TODO: CI/CD 设置
[ ] 选择 CI/CD 平台
[ ] 创建管道配置
[ ] 设置构建阶段
[ ] 添加测试阶段
[ ] 配置部署阶段
[ ] 设置环境变量
[ ] 测试管道
`

### 3. 完成任务

Kiro 完成任务，随着您的进行将其标记为完成。

### 4. 稍后恢复

`> /todo resume

? 选择要恢复的待办列表: ›
❯ ✗ CI/CD 设置 (4/7)

# 从中断的地方继续
`

### 5. 完成后清理

`> /todo clear-finished`
