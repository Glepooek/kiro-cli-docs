# 委托

**弃用通知**

实验性的委托工具将在未来版本中被官方的 [子代理](../chat/subagents.md) 工具取代。我们建议在新工作流中使用子代理。

委托启用启动和管理异步任务进程，允许您并行运行具有特定代理的 Kiro 聊天会话与您的主对话。子代理通过提供专门的代理扩展了这一能力，这些代理可以自主处理复杂任务并提供实时进度跟踪。

## 概述

委托功能允许您：
- 使用自然语言启动后台任务
- 使用特定代理并行运行 Kiro 聊天会话
- 独立监控任务进度
- 在任务运行时继续您的主对话

## 启用委托

```bash
kiro-cli settings chat.enableDelegate true
```

或使用实验命令：

```bash
/experiment
# 从列表中选择 "Delegate"
```

## 工作原理

### 任务创建

使用自然语言让 Kiro 启动后台任务：

`> 你能创建一个后台任务来分析我们 API 端点的性能吗？`

Kiro 会：
1. 理解任务需求
2. 确定是否需要代理
3. 如果使用代理则请求批准
4. 在后台启动任务
5. 将控制权返回给您的主对话

### 代理审批流程

**带代理的任务：**
- 需要明确批准
- 执行前显示代理详情
- 显示代理配置和权限

**不带代理的任务：**
- 以信任所有权限的警告运行
- 可能有更广泛的工具访问权限

### 任务管理

委托后，任务独立工作。您可以：
- 随时检查进度
- 完成后读取结果
- 不再需要时删除任务

## 任务生命周期

### 1. 创建

`> 创建一个后台任务来 [描述]`

Kiro 分析请求并确定：
- 需要什么代理（如果有）
- 需要什么工具
- 访问什么资源

### 2. 批准（如果需要）

如果需要代理，您会看到：

`代理: task-agent-name
描述: 这个代理做什么
工具: 它可以使用的工具列表
资源: 它可以访问的文件

批准这个代理？(y/n):
`

### 3. 执行

任务在后台运行，同时您继续主对话。

### 4. 监控

随时检查状态：

`> 检查 [任务名称]
> 我的后台任务状态如何？
> 展示任务进度
`

### 5. 完成

完成后，您可以：

`> 展示 [任务名称] 的结果
> 后台任务发现了什么？
`

### 6. 清理

完成后删除任务：

`> 删除 [任务名称] 任务
> 清理已完成的任务
`

## 最佳实践

### 何时使用委托

- **长时间运行的操作**：测试套件、构建、分析
- **独立任务**：不需要您输入的工作
- **并行工作**：可以同时运行的多个任务
- **后台监控**：持续检查或监视

### 何时不使用

- **交互式任务**：需要您输入的工作
- **快速操作**：几秒钟完成的任务
- **依赖工作**：需要主对话结果的任务
- **简单命令**：直接执行更快

### 任务组织

- **使用描述性名称**：使任务易于识别
- **监控进度**：定期检查长时间运行的任务
- **清理已完成的任务**：不再需要时删除
- **限制并发任务**：太多可能会减慢系统

## 安全考虑

### 代理批准

在批准之前始终查看代理详情：
- **工具**：代理可以做什么？
- **资源**：它可以访问什么文件？
- **权限**：允许什么操作？

### 信任所有警告

不带代理运行的任务具有提升的权限：
- 可以访问所有工具
- 可能有更广泛的文件访问权限
- 应谨慎使用

### 最佳实践

1. **查看代理配置**：了解您在批准什么
2. **使用特定代理**：创建具有最小必需权限的代理
3. **监控任务活动**：检查任务在做什么
4. **删除敏感结果**：清理包含敏感数据的任务

## 限制

### 并发性

- 并发任务数量有限
- 系统资源在任务之间共享
- 许多任务可能会影响性能

### 任务隔离

- 任务独立运行
- 无法直接与主对话通信
- 结果必须显式检索

### 持久化

- 任务是会话范围的
- 可能无法在会话重启后存活
- 如果需要长期保存，结果应该保存

## 故障排除

### 任务不启动

1. **验证委托已启用**：
   
   ```bash
   kiro-cli settings chat.enableDelegate
   ```
2. **检查错误**：在聊天中查找错误消息
3. **尝试更简单的任务**：先用基本任务测试

### 无法检查任务状态

1. **验证任务 ID**：确保您使用正确的任务名称/ID
2. **检查任务是否完成**：已完成的任务可能已被清理
3. **列出所有任务**：让 Kiro 显示所有活动任务

### 代理批准问题

1. **仔细查看代理详情**：确保您理解权限
2. **检查代理是否存在**：验证代理已正确配置
3. **尝试不带代理**：某些任务可以在没有特定代理的情况下运行

## 高级用法

### 为任务创建自定义代理

为常见的后台任务创建专门的代理：

```json
{
  "name": "test-runner",
  "description": "在后台运行测试套件",
  "tools": ["shell", "read"],
  "allowedTools": ["shell"],
  "toolsSettings": {
    "shell": {
      "allowedCommands": ["npm test", "pytest", "cargo test"]
    }
  }
}
```

### 任务模式

**分析任务：**

`> 在后台分析代码质量
> 作为后台任务运行安全扫描
> 在后台生成性能报告
`

**构建任务：**

`> 在后台构建项目
> 作为后台任务编译并运行测试
> 在后台生成生产包
`

**监控任务：**

`> 在后台监控日志文件
> 作为后台任务监视文件更改
> 在后台跟踪系统指标
`
