# 自定义 Agent 故障排除

## 概述

本指南帮助您诊断和解决在 Kiro CLI 中创建和使用自定义 Agent 时的常见问题。

### 配置错误

#### 无效的 JSON 语法

**问题**: 自定义 Agent 加载失败,出现 JSON 解析错误。

**症状**:
- 错误消息提示 "invalid JSON" 或 "syntax error"
- 自定义 Agent 未出现在 `/agent list` 中
- 回退到默认 Agent 行为

**解决方案**:
- 使用 JSON 验证器或 linter 验证您的 JSON
- 检查常见的 JSON 错误:
  - 数组元素或对象属性之间缺少逗号
  - 最后一个元素后的尾随逗号
  - 括号或大括号不匹配
  - 字符串值中的引号未转义
- 使用 `/agent schema` 验证您的配置结构

#### Schema 验证错误

**问题**: 自定义 Agent 配置与预期的 schema 不匹配。

**症状**:
- 关于未知配置字段的警告
- 自定义 Agent 行为与配置不匹配
- 缺少必填字段错误

**解决方案**:
- 使用 `/agent schema` 将您的配置与 schema 进行比较
- 检查字段名是否有拼写错误(例如 `allowedTools` 与 `allowedTool`)
- 验证数据类型是否符合 schema 要求(数组与字符串,布尔值与字符串)

### 自定义 Agent 加载问题

#### 找不到自定义 Agent

**问题**: 自定义 Agent 未出现在列表中或无法使用。

**症状**:
- `/agent list` 未显示您的自定义 Agent
- 在没有警告的情况下回退到默认 Agent

**解决方案**:
- 验证自定义 Agent 文件是否位于正确的位置:
  - 全局: `~/.kiro/agents/[name].json`
  - 工作区: `.kiro/agents/[name].json`
- 检查文件权限 - 确保文件可读
- 验证文件名是否与您尝试使用的自定义 Agent 名称匹配
- 确保文件具有 `.json` 扩展名

#### 加载了错误的自定义 Agent 版本

**问题**: 加载的自定义 Agent 版本与预期不同。

**症状**:
- 自定义 Agent 行为与您最近的配置更改不匹配
- 关于自定义 Agent 冲突的警告消息
- 意外的工具可用性或权限

**解决方案**:
- 检查本地和全局目录之间的自定义 Agent 名称冲突
- 请记住,本地自定义 Agent 优先于全局自定义 Agent
- 使用 `/agent list` 查看正在加载的版本
- 如有必要,删除或重命名冲突的自定义 Agent 文件

### 工具权限问题

#### 工具不可用

**问题**: 自定义 Agent 无法访问您配置的工具。

**症状**:
- 关于未知或不可用工具的错误消息
- 自定义 Agent 请求 `allowedTools` 中的工具权限
- MCP 服务器工具不工作

**解决方案**:
- 验证工具名称在 tools 数组中拼写正确
- 对于 MCP 工具,确保服务器在 `mcpServers` 中正确配置
- 检查 MCP 服务器是否正在运行且可访问
- 使用正确的 MCP 工具语法: `@server_name/tool_name`
- 根据内置工具文档验证内置工具名称

#### /tools 命令返回空列表

**问题**: `/tools` 命令显示没有可用工具或工具少于预期。

**症状**:
- `/tools` 返回空列表
- 预期的工具从工具列表中缺失
- 自定义 Agent 似乎没有任何功能

**常见原因**:
- 自定义 Agent 配置中的 tools 数组为空
- tools 数组中的工具名称拼写错误
- MCP 服务器工具名称不正确(缺少服务器前缀)
- MCP 服务器配置问题导致工具无法加载

**解决方案**:
- 检查您的自定义 Agent 配置是否包含具有有效工具名称的 tools 数组
- 验证工具名称拼写正确(区分大小写)
- 对于 MCP 工具,确保使用正确的服务器前缀格式: `@server-name___tool-name`
- 使用默认 Agent 测试以确认工具可用 `/tools`
- 如果使用外部工具,检查 MCP 服务器状态

#### 意外权限提示

**问题**: 自定义代理提示您认为已预批准的工具的权限。

**症状**:
- `allowedTools` 中列出的工具的权限提示
- 尽管有自定义代理配置，工作流程仍中断

**解决方案**:
- 确保工具同时列在 tools 和 allowedTools 数组中
- 检查两个数组中工具名称的拼写错误
- 对于 MCP 工具，在 allowedTools 中使用完整的服务器前缀名称
- 验证 toolAliases 是否正确应用

### 调试自定义代理行为

#### 缺少上下文或资源

**问题**: 自定义代理似乎无法访问预期的文件或上下文。

**解决方案**:
- 验证 resources 数组中的文件路径是否正确且文件是否存在
- 检查 resources 中的 glob 模式是否匹配预期的文件
- 确保 hook 命令成功执行并产生输出
- 手动测试 hook 命令以验证它们在您的环境中工作
- 如果命令被截断，检查 hook 超时设置

#### MCP 服务器问题

**问题**: MCP 服务器不工作或工具不可用。

**解决方案**:
- 验证 MCP 服务器命令是否正确且可执行文件在您的 PATH 中
- 检查所需的环境变量是否已设置
- 独立测试 MCP 服务器以确保它们正常工作
- 查看 MCP 服务器日志中的错误消息
- 如果服务器启动缓慢，增加超时值

#### 测试自定义代理配置

要系统地测试您的自定义代理配置：
- 使用 JSON 验证器验证 JSON 语法
- 使用 /agent schema 根据模式检查配置
- 使用 `/agent list` 测试自定义代理加载
- 使用 `/agent swap [name]` 切换到自定义代理
- 单独测试每个工具以验证访问和权限
- 验证资源和 hooks 是否提供预期的上下文
- 测试常见工作流程以确保自定义代理按预期运行
