# 自定义代理

自定义代理提供了一种通过为不同用例定义特定配置来自定义 Kiro 行为的方式。每个自定义代理由一个配置文件定义，该文件指定代理可以访问哪些工具、拥有什么权限以及应该包含什么上下文。

默认情况下，Kiro CLI 提供对所有可用工具的访问，但大多数操作需要用户确认。这种方法优先考虑安全性，但可能会通过频繁的权限提示打断您的工作流程。

自定义代理通过以下方式解决此问题：

- **预先批准特定工具** - 定义哪些工具可以在不提示的情况下运行
- **限制工具访问** - 限制可用的工具以减少复杂性
- **包含相关上下文** - 自动加载项目文件、文档或系统信息
- **配置工具行为** - 设置工具应该如何操作的特定参数

## 使用自定义代理的好处

1. **工作流程优化** - 创建针对特定任务（如 AWS 基础设施管理、代码审查或调试会话）定制的自定义代理。
2. **减少中断** - 预先批准受信任的工具，在专注工作期间消除权限提示。
3. **增强上下文** - 自动包含相关的项目文档、配置文件或系统信息。
4. **团队协作** - 与团队成员共享自定义代理配置，确保一致的开发环境。
5. **安全控制** - 将工具访问限制为特定工作流程所需的内容，减少潜在的安全风险。

## 与 MCP 和内置工具的关系

自定义代理与内置工具和通过模型上下文协议（MCP）提供的外部工具一起工作。这使您能够灵活地：

- **使用内置工具** - 文件操作、命令执行、AWS CLI 集成和其他核心功能
- **集成 MCP 服务器** - 通过 MCP 服务器配置添加自定义工具和服务
- **控制工具访问** - 指定每个来源的哪些工具可用
- **管理工具冲突** - 使用别名处理不同工具来源之间的命名冲突
