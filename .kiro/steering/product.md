# 产品概述

## 项目目的

Kiro CLI 中文学习文档项目，旨在帮助快速、完整、准确的了解、掌握 Kiro CLI 功能。

## 目标用户

- 中文开发者
- 希望学习 Kiro CLI 的用户
- 需要本地化文档参考的开发团队

## 关键功能

1. **文档抓取** - 从 kiro.dev 官方网站获取最新文档
2. **格式转换** - 将网页内容转换为结构化的 Markdown 文件
3. **本地化整理** - 按照清晰的目录结构组织文档
4. **持续更新** - 跟进官方文档更新，保持内容同步

## 业务目标

- 降低中文用户学习 Kiro CLI 的门槛
- 提供离线可用的完整文档资源
- 建立易于维护和扩展的文档体系

## 内容来源

所有文档均来自 Kiro 官方文档网站：https://kiro.dev/docs/cli/
