# 技术栈

## 文档格式

- **Markdown** - 所有文档使用 .md 格式
- **UTF-8 编码** - 确保中文内容正确显示

## 核心工具

### Kiro CLI
- 主要工具，用于文档管理和版本控制
- 提供代码智能、文件操作、shell 命令等功能

### web-to-markdown 技能
- 用于从 kiro.dev 抓取网页内容
- 自动转换为 Markdown 格式
- 支持中文翻译

## 数据来源

- **官方文档网站**: https://kiro.dev/docs/cli/
- **URL 管理**: url_list.txt 记录所有源地址

## 技术约束

1. 文档格式必须兼容标准 Markdown 解析器
2. 文件路径使用 Windows 格式 (E:\...)
3. 目录结构遵循 docs/ 主目录分类
4. 文件命名使用小写字母和连字符

## 版本控制

- Git 仓库管理
- 主分支：main
- 提交信息使用中文描述
